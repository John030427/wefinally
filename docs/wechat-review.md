## 二、服务器域名配置（合法域名）

路径：**微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名**

### 2.1 request 合法域名

```
https://api.yourdomain.com
```

- 必须 **HTTPS**
- 必须 **ICP 备案**
- 不支持 IP、端口、路径
- 与后端 `.env` 及 Nginx 部署域名一致

### 2.2 uploadFile / downloadFile

WeFinally **无图片上传功能**，通常无需配置 uploadFile 域名。若后续增加文件下载，再按需添加 downloadFile 域名。

### 2.3 socket 合法域名

本项目不使用 WebSocket，可不配置。

### 2.4 业务域名（可选）

若 H5 页面需 web-view 打开，在 **业务域名** 中添加并下载校验文件至服务器根目录。

## 三、小程序代码配置

### 3.1 project.config.json

```json
{
  "appid": "你的AppID",
  "projectname": "WeFinally",
  "setting": {
    "urlCheck": true,
    "es6": true,
    "minified": true
  }
}
```

生产环境 **`urlCheck` 必须为 true**，开发阶段可在开发者工具临时关闭调试。

### 3.2 请求基址

`miniprogram/utils/request.js`（或等效文件）中 API 基址：

```javascript
const BASE_URL = 'https://api.yourdomain.com/api';
```

**禁止** 使用 `http://` 或未备案域名。

## 四、隐私保护与合规

### 4.1 用户隐私保护指引

在微信公众平台配置 **用户隐私保护指引**，声明收集的信息类型：

| 信息类型 | 用途 | WeFinally 是否收集 |
|----------|------|-------------------|
| 微信昵称/头像 | 本项目中**不收集头像** | 否（无头像功能） |
| 手机号 | 可选联系 | 选填 |
| 性别、年龄、学历等 | 婚恋匹配 | 是 |
| 位置信息 | 同城匹配 | 按城市选择，非 GPS 强制定位 |
| 设备信息 | 合规授权日志 | 授权时记录 |

### 4.2 隐私协议弹窗（微信官方组件）

在 `app.json` 中配置：

```json
{
  "__usePrivacyCheck__": true
}
```

注册页必须 **独立勾选** 三项协议（不可默认勾选）：

1. 《用户服务协议》
2. 《隐私政策》
3. 《个人信息授权协议》

授权记录写入 `user_privacy_auth_log` / `user_agreements` 表。

### 4.3 无社交、无 UGC 图片

审核重点说明：

- **无用户头像、相册、图片/视频上传**
- **用户间无私聊、无动态、无点赞评论**
- 仅平台 AI 客服，异常场景转人工

可在审核备注中明确写出以上设计，降低「社交 UGC」类审核风险。

## 五、类目与资质

### 5.1 婚恋类目常见资质

- 营业执照（经营范围含婚恋/信息服务等）
- 部分情况需 **增值电信业务经营许可证（ICP 证）** 或地方婚恋服务备案
- 以微信当前类目审核要求为准，提交前在公众平台查看 **类目资质说明**

### 5.2 付费功能

- 会员 188 元/30 天，需在小程序内清晰展示价格与权益
- 接入微信支付（见 [wechat-pay.md](./wechat-pay.md)）
- 无自动续费，需在界面明确标注


## 七、提交审核前自检清单

### 7.1 功能自检

- [ ] 未登录可浏览欢迎页，核心功能需登录
- [ ] 注册三项协议必须手动勾选
- [ ] 无任何图片/视频上传入口
- [ ] 无用户私聊、无动态广场
- [ ] 会员价格、权益、有效期展示清晰
- [ ] 空数据、加载中、网络错误有友好提示
- [ ] 个人中心可查看协议与注销入口

### 7.2 配置自检

- [ ] AppID 与后台一致
- [ ] request 合法域名已保存并生效（需重新编译上传）
- [ ] 隐私保护指引已填写并发布
- [ ] 服务器 HTTPS 证书有效
- [ ] `/api/common/health` 可访问

### 7.3 内容自检

- [ ] 无测试账号密码硬编码在界面
- [ ] 无「最好」「第一」等绝对化用语
- [ ] 无虚假成功案例或夸大宣传

## 八、常见拒审原因与处理

| 拒审原因 | 处理方式 |
|----------|----------|
| 类目资质不全 | 补充营业执照/ICP 等资质 |
| 涉及社交 UGC | 强调无用户发帖、无私聊、无头像 |
| 隐私协议不合规 | 完善隐私指引，启用官方隐私弹窗 |
| 域名未配置 | 配置 HTTPS 合法域名 |
| 付费说明不清 | 补充会员权益页、价格说明 |
| 功能不完整 | 确保注册-匹配-支付主流程可演示 |

## 九、体验版与审核版账号

建议准备 **2 个测试账号**（一男一女 VIP），便于审核人员体验：

1. 账号 A：已注册、已开通 VIP、有匹配记录
2. 账号 B：普通注册用户

在审核说明中提供测试路径，**勿提供合伙人/管理员后台入口**。
