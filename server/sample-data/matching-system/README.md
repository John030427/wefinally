# Matching System Sample Database

This folder contains deterministic sample data for the full matching chain:

1. Algorithm matching
2. Mock AI rerank
3. Mock AI report
4. Report failure fallback
5. Scenario coverage fixtures for high-fit, one-sided fit, psych conflict, cross-city, education gap, appearance hit/miss, small-pool fallback, AI rerank reversal, and report failure fallback
6. Wave 2 executable cases for narrow first-match, age boundary, legacy missing relationship preferences, unlimited baby-plan preference, height boundary, appearance synonym hit, soft relationship difference, and 3-candidate AI rerank

Run from `server/`:

```bash
npm run sample:match-e2e
```

Useful individual commands:

```bash
npm run sample:match-clear
npm run sample:match-seed
npm run sample:match-run
```

All sample users use the `sample_match_` openid prefix. The scripts only clear users and match records under that prefix.
`latest-run.json` is regenerated by `sample:match-run` and `sample:match-e2e` for review.

Wave 2 cases are declared in `fixtures.json.caseBatches` and asserted through `expected-results.json.wave2`.
Each case uses a separate openid prefix and batch date, so a failed case can be found directly in `latest-run.json.summary.wave2Cases`.
