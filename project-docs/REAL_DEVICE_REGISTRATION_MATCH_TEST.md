# 真机重新注册与匹配结果测试资料

适用日期：2026-08-30。此方案只用于两台真实微信账号的受控 QA，不用于正式用户造数。

## 测试前置条件

两台真机账号都需要满足：

- `account_mode` 保持 `production`，并单独设置 `qa_test_run_enabled = true`；不要改成 `internal_qa`，后者按现有安全规则不进入正式候选池。
- 会员审核状态为 `approved`，VIP 在有效期内，账号状态为正常。
- 两台账号都从首页“内部 QA”区域点击“重新注册测试资料”。该动作会给两台账号写入同一个隔离测试组 `qa-real-device-registration-v1`，测试组只能匹配组内账号，不会匹配正式用户。
- 完成资料和择偶配置后，再运行下一轮匹配。若该两人历史上已经互相匹配过，现有“避免重复匹配”规则仍会生效；首次验证请使用尚未互配过的两个账号。

“重新注册测试资料”不会删除账号、历史匹配、订单、VIP、推广归属或审核状态；它只开启一次性资料重录、清空当前择偶配置并解除 7 天编辑冷却。

## 匹配结果动画验证

1. 完成一次匹配后，不要先打开首页，在匹配日期之后再打开小程序。
2. 首页取得最新匹配后，会显示“新的匹配已经抵达”动画。
3. 点击“立即查看”进入该条匹配详情；点击“稍后再看”关闭动画。
4. 同一账号、同一条匹配只展示一次。已看记录按用户 ID 存在本机，不会串到另一台测试账号。
