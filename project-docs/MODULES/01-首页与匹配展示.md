# 模块 01：首页与匹配展示

## 代码位置

| 页面 | 路径 |
|------|------|
| 匹配首页 | `miniprogram/pages/index/` |
| 匹配记录 | `miniprogram/pages/match-list/` |
| 匹配详情 | `miniprogram/pages/match-detail/` |

## 功能说明

- **index**：VIP 状态、最新一条匹配、下次匹配时间（动态算出周三/五日期）、快捷入口
- **match-list**：历史匹配列表 + 三观契合度标签
- **match-detail**：对方基础标签、三观契合度进度条、奔现对接（AI 客服）

## 已确认产品规则（2026-06-29）

| 规则 | 结论 | 来源 |
|------|------|------|
| **非 VIP 看匹配详情** | 只展示**模糊提示 + 开通 VIP 引导**；完整 AI 匹配详情仅有效 VIP 可见 | Q1 |
| **详情展示字段（最小集）** | 年龄段、学历、职业圈层、婚育计划、基础硬性条件、**身高区间档位**、三观契合度 | Q2 |
| **详情隐藏字段** | 姓名、照片、联系方式、**性别、城市、精确身高**一律不展示 | Q2、Q4 |
| **外貌描述** | v1 **不在详情展示**（仅存储 + 后台辅助，见模块 03） | Q4 / B-Q2 |
| **见面安全确认入口** | 在 match-detail 的奔现卡内增按钮（官方对接后附加层，P2） | Q5 / B-Q3 |
