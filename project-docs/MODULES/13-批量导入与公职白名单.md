# 模块 13：批量导入与公职/教师/医护免费白名单

> 来源：老板原话 A8 +《深圳群团_工会对接 + 公务员免费入驻批量上传 可行性合规方案.docx》。
> 老板原话：「针对这三大人群我根据资源对接的成熟度会让他们批量导入，免费，**你先留好接口**」。

## 目标
对接深圳工会/群团/学校/医院官方，**单位主导批量导入白名单** → 平台批量开通**终身免费会员**（豁免 188/月）+ 专属圈层标签。这是平台的官方背书与最高信任壁垒。

## 三大人群
| 圈层 | 标签 | 对接单位 |
|------|------|----------|
| 公务员 / 参公 / 事业编 / 国企 | 【公职公益认证】 | 各区工会、机关工委、群团 |
| 在编公办教师 | 【深圳教育公益认证】 | 教育工会、学校工会 |
| 在岗医护（医生/护士） | 【深圳医护公益认证】 | 卫健委、医院工会、医务群团 |

## 两种入驻模式
- **模式一（主推·零风险）单位官方批量白名单**：单位统一收集 → **脱敏提交（仅姓名+手机号+单位）** → 平台后台**批量导入**、批量开通终身免费会员、打圈层标签。
- **模式二（补充）个人公职认证免费**：用户自传 工作证/在职证明/工号（教师证/执业医师证/护士证）→ 人工审核 → 终身豁免会费。

## 「先留好接口」= v1 现在要做的最小件
老板要的是**先把接口/数据结构预留好**，不是立刻全做后台 UI。最小落地：
1. **DB**：`user` 增 `free_member`(tiny#)、`free_source`(public/edu/med)、`whitelist_unit`(单位名)；或新表 `free_whitelist`。免费用户 `is_vip` 永久有效或单独豁免逻辑。
2. **批量导入 API**（管理员/受信单位用）：`POST /api/admin/whitelist/import`，入参为脱敏名单数组（姓名+手机号+单位+圈层），幂等、留痕。
3. 匹配/详情展示圈层标签（复用现有 circle/tag 渲染）。
4. 后台手动导入页 + 模式二人工审核——可二期。

> ponytail：v1 只做「DB 字段 + 批量导入 API + 免费会员豁免逻辑 + 标签」，单位自助上传门户/模式二审核 UI 等有真实单位对接时再做。

## 合规红线（必须遵守）
- **批量上传必须由单位主导、平台只接收**，平台不得私自采集公职/教师/医护名单。
- 脱敏数据加密存储，不外泄、不商用、不引流。
- 宣传口径：「面向机关/教育/医疗青年人才**公益婚恋帮扶**」，不炒作职业标签、不猎奇。
- 仅对在岗正式人员开放，杜绝冒用/代认证。
