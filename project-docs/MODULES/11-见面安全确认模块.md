# 模块 11：见面安全确认

> **用户新增需求 C2/C3** + **项目总目标：提升女性安全感与线下见面转化**

## 产品定位（已确认）

- **不是**用户自助发起私下见面
- **是**官方客服对接奔现**之后**的「用户自我安全确认」附加层
- 用户文案：**线下见面安全确认**（不用「强制报备」）
- 内部/DB：`meet_report`

## 第一版 MVP 范围

### 做

1. 线下见面安全确认表单
2. 见面时间、地点、见面对象、见面说明
3. 安全提示勾选「我已阅读线下见面安全提示」
4. 报备状态
5. 历史记录列表
6. 见面安全卡（脱敏）
7. 用户主动转发——**仅转发给自己的微信好友/家人**（`open-type="share"`）

### 不做

- 实时定位、紧急联系人、用户端上传照片
- 复杂风控模型
- 默认展示手机/身份证/真实姓名
- **不在小程序内把安全卡发给匹配对象、不公开展示**（Q5）
- **不做"保存相册图片"**（v1，Q5）

## 见面安全卡字段

1. 见面对象昵称或脱敏标识
2. 预计见面时间
3. 预计见面地点
4. 见面说明
5. 安全提示
6. 小程序名称
7. 生成时间
8. 安全卡编号 / 记录 ID
